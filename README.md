# 🐉 드래곤 라자 : 헬턴트 영지 3D (Project Heltant 3D)

> **"인간은 단수가 아니다. 우리는 복수다."**  
> 이영도 작가의 한국 판타지 문학 걸작 《드래곤 라자(Dragon Raja)》의 시작 무대인 **헬턴트 영지(Heltant Village)**를 WebGL / Three.js 기반 실시간 3D 가상 세계로 완벽하게 재현한 인터랙티브 탐험 프로젝트입니다.

---

## 🌟 주요 특징

1. **원작 7대 랜드마크 3D 완벽 구현**:
   - **중앙 광장 & 석조 우물**: 마을의 중심, 두레박과 4방향 이정표 (임펠 가도 / 서쪽 숲 / 영주 저택 / 후치 공방)
   - **후치 네드발의 집 & 초 공방**: 밀랍 냄새 배어있는 작업실, 양초 간판과 촛불
   - **칼 헬턴트의 서재 / 영주 저택**: 웅장한 2층 석조 저택과 천문 관측 첨탑
   - **헬턴트 선술집 (타이번의 주점)**: 맹인 마법사 타이번과 조우했던 유서 깊은 주점, 야외 맥주통과 벤치
   - **샌슨의 경비대 막사 & 대장간**: 타오르는 모루 화덕, 무기 거치대, 목제 훈련 인형
   - **서쪽 감시 망루 & 방책 성벽**: 붉은 서쪽 숲을 감시하는 거대한 목조 망루와 봉화대
   - **물레방아와 시냇물**: 회전하는 목제 수차와 영지를 가로지르는 맑은 개울, 돌다리

2. **서쪽 지평선의 감시자 — 블랙 드래곤 아무르타트 (Amstatus)**:
   - 헬턴트 영지 서쪽 하늘 위, 거대한 날개를 펄럭이며 영지를 굽어보는 아무르타트의 장엄한 실루엣과 붉은 안광 구현.

3. **1인칭 / 3인칭 자유 시점 전환 (`V` 키)**:
   - **1인칭 시점**: 후치 네드발의 눈으로 직접 헬턴트 마을을 누비는 몰입형 시점.
   - **3인칭 시점**: 등에 바스타드 소드를 메고 모험가 복장을 한 후치 3D 캐릭터 모델 추적.

4. **오거 파워 건틀릿 (OPG) 마력 발동 (`G` 키)**:
   - 타이번에게 물려받은 괴력의 마법 장갑 OPG를 활성화하여 붉은 마력 오라와 비네트 이펙트 체험.

5. **3대 시간대 & 조명 무드 전환 (`T` 키)**:
   - **황혼 석양 (Dusk)**: 아무르타트의 서쪽 숲을 붉게 물들이는 장엄한 석양과 긴 그림자.
   - **달빛 밤 (Night)**: 푸른 달빛과 횃불, 마을 가옥들의 따스한 창문 불빛.
   - **청명한 아침 (Day)**: 맑고 쾌청한 바이서스 북서부의 아침 햇살.

6. **원작 명대사 & 해설 양피지 모달 (`E` 키)**:
   - 각 랜드마크 접근 시 상호작용 프롬프트 표시, `E` 키를 누르면 원작 소설의 명대사와 비하인드 스토리가 담긴 양피지 카드 호출.

7. **실시간 레이더 미니맵 & Web Audio API 자체 합성 사운드**:
   - 우측 상단 실시간 Canvas 미니맵 (플레이어 위치, 시선 원뿔각, 랜드마크 핀).
   - 외부 음원 다운로드 없이 브라우저 Web Audio API로 자체 합성된 바람 소리, 횃불 타닥임, 발걸음, OPG 펄스 효과음.

## 🎮 조작법 (Controls)

| 키 | 기능 |
|:---:|:---|
| **`W` `A` `S` `D`** / **방향키** | 전후좌우 보행 이동 |
| **`Shift`** | 전력 질주 (Sprint) |
| **`Space`** | 점프 (Jump) |
| **마우스 좌클릭** | 화면 시점 고정 (Pointer Lock) / 드래그 회전 |
| **`V`** | 1인칭 ↔ 3인칭 시점 전환 |
| **`E`** | 랜드마크 조사 및 원작 대화 확인 |
| **`G`** | OPG (오거 파워 건틀릿) ON / OFF 토글 |
| **`T`** | 시간대 전환 (황혼 석양 ↔ 달빛 밤 ↔ 청명한 아침) |
| **`M`** | 사운드 켜기 / 끄기 (Mute) |

## 🚀 실행 방법

### 방법 1. 간편 실행 (Windows 배치 파일)
`start.bat` 파일을 더블클릭하면 로컬 웹 서버가 자동 구동되고 기본 브라우저가 열립니다.

### 방법 2. Python 로컬 서버 실행
```bash
cd heltant-3d-village
python server.py
# 브라우저에서 http://localhost:8080 접속
```
